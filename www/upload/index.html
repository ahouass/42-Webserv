📁 File Upload

Upload via Form (multipart/form-data)

Supported: Multiple file upload via multipart/form-data
Max size: 50MB per request for this location

🧪 Test with curl

You can also test uploads via command line:

# Single file upload
curl -X POST http://localhost:8080/uploads -F "file=@myfile.txt"

# Multiple files
curl -X POST http://localhost:8080/uploads -F "file=@file1.txt" -F "file=@file2.txt"

# With description
curl -X POST http://localhost:8080/uploads -F "file=@myfile.txt" -F "description=My upload"
